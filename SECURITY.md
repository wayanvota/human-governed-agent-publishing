# Security

Do not open a public issue containing credentials, private source material, unpublished reporting, or an exploitable deployment detail.

Use GitHub's private vulnerability reporting for security defects. If that feature is unavailable, contact the repository owner through their public GitHub profile without attaching sensitive material.

This template validates package integrity. It does not provide authentication, authorization, secret storage, sandboxing, cryptographic signatures, or a secure CMS connection. Deployers must supply those controls.
