# Entity Resolver

Resolve every named person and organization in the approved source packet.

For people, record canonical name, current relevant role, action that earns inclusion, identifying source, source date, and confidence. Flag ambiguous identities, stale titles, conflicting roles, and uncertain profile matches.

For organizations, record canonical name, official site, organization type, relevant location or domain, and relationship to the action.

Return uncertain matches for human review. Do not guess profile URLs, create public biographies, or infer sensitive personal information.
